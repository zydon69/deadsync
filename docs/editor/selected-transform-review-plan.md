## One engine, separate collision contracts

`transform/preview.rs` factors the existing spatial implementation into a pure
Grid preview reused by legacy row-range transform::apply and public
apply_positions. It preserves remove-all/order/ForceInsert/Pad mapping behavior.
Owner preview is a separate strict insertion path and typed OwnerCollision.
Kind conversion still calls the shared note_operation::convert_note rule.
No second mirror, lane-wrap, ForceAdd or owner mutation algorithm exists.

`selected_transform::Plan` captures exact requested heads by whole-chart,
checked-head or explicit row range, validates sparse scan bounds/cancellation,
and stores final changed edits plus chart GUID and monotone IntentGuard. It
reports source heads moved/deleted and other original heads deleted/replaced/
shortened. Destructive effects are exact typed Impact identities (Position+kind).
An unchanged/unsupported symmetry head is not silently included as a transformed
note. A source boundary deletion also needs review. Every impact must be
individually acknowledged; missing/extra acknowledgements and stale/foreign/
changed-focus plans leave content and Undo/Redo untouched. Undo restores every
spatial side effect through the single existing notes transaction.

Cooperative cancellation and a default2,000,000 original-head bound do not make
Grid loading/cloning/ForceInsert interruptible, nor establish a peak-memory cap.

## Native keyboard review

F9 in mixed checklist opens exact checked spatial/player transformations. F8
inside Transformations opens the same eight-row optional panel using the current
row range; whole-chart scope is an explicit native convenience. Operations cover
Mirror, Flip, combined symmetry, lane shift/wrap, earlier/later, assignment and
player exchange. Player fields affect only owner operations. Prepare never edits.

Review displays counts and one typed destructive effect at a time. Left/Right
browse impacts; Enter acknowledges one. Cursor traversal uses BTreeSet range
successor/predecessor O(log n), not repeated nth scans over a large set. Apply
requires the full exact impact set. Parameter changes discard the prior review.
Cancel returns to the original checklist/Transformations panel. Apply consumes
its old selection snapshot and refreshes the chart.
